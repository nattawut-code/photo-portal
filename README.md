# Photo Portal — GitHub Pages POC

เว็บต้นแบบ Mobile First สำหรับค้นหารูปกิจกรรมด้วยใบหน้า โดยประมวลผล selfie และการค้นหาบนเบราว์เซอร์ของผู้ใช้ ไม่มี AI API หรือ AI server

## เปิดใช้

1. อัปโหลดโฟลเดอร์นี้ไป GitHub repository แล้วเปิด **Settings → Pages → Deploy from a branch → main / root**
2. เปิดเว็บผ่าน HTTPS (GitHub Pages) เพื่อใช้กล้องมือถือได้
3. เปลี่ยน `EVENTS` ใน `assets/app.js` เป็นชื่อกิจกรรมและลิงก์ Google Photos album จริง
4. เปิดส่วน **เครื่องมือ POC: สร้าง Face Index** เลือกรูปกิจกรรม (สูงสุด 100 รูป) แล้วดาวน์โหลด `face-index.json`
5. แทนที่ `data/demo-index.json` ด้วยไฟล์นั้น แล้ว deploy ใหม่

## สิ่งที่ POC นี้ทดสอบ

- ขนาดและเวลาโหลดโมเดล face recognition บนมือถือ
- เวลาสร้าง descriptor จาก selfie และเทียบกับ Face Index 100 รายการ
- ความแม่นยำกับภาพกิจกรรมจริง (ต้องใช้ index ที่สร้างจากภาพกิจกรรม)

`data/demo-index.json` ตั้งใจให้ว่าง เพื่อไม่อ้างว่าการจับคู่ถูกต้องก่อนมีชุดภาพที่ได้รับอนุญาตจริง ส่วนรูปตัวอย่างในหน้าผลลัพธ์จะปรากฏหลังสร้าง index เท่านั้น

## ข้อจำกัดก่อนใช้งานจริง

- ผู้สร้าง Index ต้องเปลี่ยน `url` ของแต่ละรายการให้เป็น URL รูป/อัลบั้ม Google Photos จริง (หน้า POC ใช้ URL อัลบั้มเป็นค่าเริ่มต้น)
- ลิงก์รูปและ embedding ถูกเผยแพร่เป็นไฟล์สาธารณะบน GitHub Pages จึงต้องได้รับอนุญาตผู้ปกครอง/โรงเรียน และทำเอกสารความเป็นส่วนตัวก่อนใช้จริง
- ไม่ควรนับ POC นี้เป็นระบบยืนยันตัวตน; ให้ผู้ใช้ตรวจรูปเองเสมอ

## โครงสร้าง

- `index.html` — หน้าจอเลือกกิจกรรม, ค้นหา และผลลัพธ์
- `assets/app.js` — งาน AI และ UI ทั้งหมดบนอุปกรณ์ผู้ใช้
- `data/demo-index.json` — Face Index ที่ deploy ไปพร้อมเว็บ
